# Amani

Amani is a React Native Expo app for Android focused on mental health community support for Kenyan users.

## Getting Started

Install dependencies:

```bash
npm install
```

Run on Android:

```bash
npm run android
```

## Project Structure

- `src/screens` - App screens.
- `src/components` - Shared UI components.
- `src/navigation` - Root, auth, and tab navigators.
- `src/services` - External service setup such as Firebase.
- `src/assets` - App images, icons, and static assets.

## Firebase

Add your Firebase web app credentials in `src/services/firebase.ts`.
